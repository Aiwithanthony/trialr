# Trialr — Design Context

## Target audience

One person: the creator who owns the account. Not a team, not a client, no
onboarding funnel. They already know what a Trial Reel is. The app is opened
deliberately for a short session — publish a batch, or check who is winning —
and then closed. It runs on their own machine or on a private hosted instance
behind a password. Nobody else ever sees this interface.

## Use cases

1. Stage up to ten vertical videos, name each variation, write one shared
   caption, and publish them as separate Instagram Trial Reels.
2. Come back later, refresh analytics, and work out which variation won.

Everything else is in service of those two jobs.

## Brand personality and tone

**Darkroom studio.** Cinematic, video-first, quiet. The reference is a
colour-grading suite or a photographer's contact sheet — not a SaaS analytics
dashboard.

- The footage is the interface. Thumbnails are the largest, brightest thing on
  screen; chrome recedes around them.
- Warm near-black ground, never blue-black, never pure `#000`.
- Colour is signal, not decoration. A single desaturated safelight amber marks
  what is live, selected, or actionable. Nothing glows.
- Restraint over emphasis. If a mark does not carry information, remove it.
- The leader in a test is annotated the way a photographer rings a keeper on a
  contact sheet, not with a badge and a flame icon.

## Explicitly rejected

These read as machine-generated and must not come back:

- Monospace type as shorthand for "technical". Pseudo-terminal kickers like
  `SYS_TRIAL_READY // 01` or `PUBLISHING_CONSOLE // V2` were decoration
  dressed as telemetry.
- Dark canvas plus a saturated glowing accent.
- Inter, Roboto, Open Sans, Arial, system-default stacks.
- Gradient text, glassmorphism, drop-shadowed rounded rectangles, cards nested
  in cards, sparklines used as ornament.

## Type

- Display: **Bricolage Grotesque** — headings, test names, variant labels.
- Text and data: **Archivo** — UI copy and every number. Analytics tables use
  `font-variant-numeric: tabular-nums` so columns align while scanning.

## Theme

Dark is the primary design target; light is derived from the same tokens. All
three appearance modes (Light, System, Dark) must stay functional.
